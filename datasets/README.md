# Dataset placement

Download the separate dataset archive and extract it into the repository root.
The archive must populate this `datasets/` directory and the top-level
`contexts/` directory. See the main `README.md` for the required paths.

Dataset payloads are ignored by Git. The `.gitkeep` files preserve the expected
empty directory structure in the source repository.

The source-document filenames for the four energy-storage datasets are:

```text
datasets/BMS/context/BMS.md
datasets/HLIB/context/HLIB.md
datasets/FLB/context/FLB.md
datasets/PB/context/PB.md
```
